# ✂️ Bold Men's

> A modern, elegant, and fully responsive website for a premium men's barbershop, featuring dark mode, multilingual support, and smooth animations.

## ✨ Features

- 🎨 **Modern UI/UX** - Clean and sophisticated design with smooth animations using Framer Motion
- 🌓 **Dark/Light Mode** - Seamless theme switching with persistent user preferences
- 🌍 **Multilingual Support** - Built-in internationalization (i18n) for multiple languages
- 📱 **Fully Responsive** - Optimized for all devices from mobile to desktop
- ⚡ **Lightning Fast** - Built with Vite for optimal performance and instant HMR
- 🖼️ **Dynamic Gallery** - Showcase barbershop work with an interactive image gallery
- 👨‍💼 **Barber Profiles** - Dedicated section to highlight team members
- 💬 **Google Reviews Integration** - Display authentic customer testimonials
- 📞 **WhatsApp Integration** - Direct contact button for easy booking
- 🛍️ **Secret Collection Page** - Exclusive product showcase with modal views
- 🎯 **SEO Optimized** - Semantic HTML and optimized assets for better search rankings

## 🛠️ Tech Stack

- **Framework:** React 18.3
- **Build Tool:** Vite 5.4
- **Routing:** React Router DOM 7.13
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion 12.33
- **Code Quality:** ESLint

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/boldmens-salon.git

# Navigate to project directory
cd boldmens-salon

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview production build
npm run preview
```
